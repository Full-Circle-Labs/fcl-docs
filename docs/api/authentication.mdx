# Authentication

The FCL API uses Bearer token authentication. Every request must include a valid API key.

## Generating an API key

Once logged into your account, click on the toolbox icon (<img src="/img/icon-dev-docs.png" alt="toolbox icon" style={{width: '3%'}} />) and select API Keys in the drop down menu. 
You will reach the API keys management dashboard (Figure 1). Fill the key name and click on "Add". The key will be displayed, store it securely because it is only displayed once at creation time.

## Including your key in requests

Store your API keys in a `.env` file that you load with `source .env` when opening a new terminal.
Pass your API key in the `Authorization` header:

```
Authorization: Bearer $YOUR_API_KEY
```

### Examples
How to structure your `.env` file:
```bash
YOUR_API_KEY=<API_KEY>
```

## Rotating keys

You can rotate a key at any time from the dashboard without downtime, create the new key, update your integration, then delete the old key on the API Keys management dashboard.

## Security best practices

Never commit API keys to source control. Use environment variables or a secrets manager to keep keys out of your codebase.
