# Quickstart

This guide walks you through the set up of your environment to make your first request to the FCL API.
:::warning
This API is currently experimental, breaking changes will occur. We invite you to share feedback and suggestions by getting in touch at contact@fullcirclelabs.bio
:::


## Prerequisites

Before you begin, you will need an FCL account and an active API key to submit requests. 
If you don't have an account, you can create one [here](https://v1.fcl.bio/). See [Authentication](./authentication) for instructions on generating a key.

## Base URL

All API requests are made to the following base URL:

```
https://api.fcl.bio/v1
```

## Your first request

Use the products endpoint to confirm your setup is working:

```bash
curl -H "Authorization: Bearer $YOUR_API_KEY" \
  https://api.fcl.bio/v1/products
```

## Next steps

Once you have confirmed connectivity, explore the [API Endpoints](/docs/reference/fcl-api) for the full list of available endpoints, or read our [Order with the API](./making-requests) guide for the details on placing your order with Python.

A typical workflow follows these steps:

1. `GET /products` to find the code of the product you want to order
2. `GET /virtual_cards` to check your virtual cards and available balance
3. `POST /cart` to add your samples
4. `POST /orders` to place and pay for the order
5. `GET /orders/{order_number}` to poll for status and results
6. `GET /orders/{order_number}/fasta` to retrieve the assembled sequence for each sample
