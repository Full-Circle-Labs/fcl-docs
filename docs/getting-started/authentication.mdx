# Authentication

The FCL API uses bearer token authentication. Every request must include a valid API key.

## Generating an API key

API keys are managed from your account dashboard. Navigate to **Settings → API Keys** and select **New Key**. Store the key securely — it is only displayed once at creation time.

## Including your key in requests

Pass your API key in the `Authorization` header:

```
Authorization: Bearer YOUR_API_KEY
```

## Key scopes

Keys can be scoped to limit access to specific resources or operations. Assign the minimum scope needed for each integration to reduce exposure if a key is compromised.

## Rotating keys

You can rotate a key at any time from the dashboard without downtime — create the new key, update your integration, then revoke the old key.

## Security best practices

Never commit API keys to source control. Use environment variables or a secrets manager, and set expiry dates on long-lived keys where supported.
