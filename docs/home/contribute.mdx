# Contribute

The FCL documentation is open source and contributions are welcome, whether it's fixing a typo, clarifying a guide, or adding a missing example.

The source lives at [github.com/Full-Circle-Labs/fcl-docs](https://github.com/Full-Circle-Labs/fcl-docs).

## How to contribute

1. Open an issue to report a problem or suggest an improvement.
2. Fork the repository, make your changes, and open a pull request.

See the repository README for setup instructions.
